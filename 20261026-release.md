
1. Update and install
```bash
cd ~/src/archivis && git pull
go build -o archivis ./cmd/archivis
sudo install -m 755 archivis /usr/local/bin/archivis
archivis version     # should show the merged commit
archivis setup       # nothing new to download; it's quick
```

2. Full Disk Access. macOS can drop it when the program is replaced. Check System Settings → Privacy & Security → Full Disk Access → /usr/local/bin/archivis.

3. Restart the web interface and watch the log
```bash
launchctl kickstart -k gui/$(id -u)/com.archivis.serve
tail -f ~/Library/Logs/archivis-serve.log
```
- The catalogue updates itself when Archivis opens it; nothing is re-indexed.
- Albums then works out folder counts and covers in the background. That takes about 5–20 seconds per million photos, depending on how many folders there are.
- Wait for a log line like grouped: … N folders (N updated). Until then the Albums page says the folders are still being worked out.

4. Tell Albums where to start. Use the same folders as in your nightly index job (~/Library/LaunchAgents/com.archivis.index.plist):
```bash
archivis roots add /Volumes/Archive1 /Volumes/Archive2
archivis roots       # check the list
```

The 02:30 index run would record them anyway; this just saves the wait. Apple Photos libraries show up as the iPhone album without being added.

5. Check in the browser. Albums should show your folders, each with a cover and a count, plus iPhone. Then open a folder and check:
- the breadcrumb, the subfolders, and every photo below it;
- that sorting and filtering stay inside the folder;
- that the search box says “Search this album” and stays in it.

6. Canon CR3 files already in the catalogue. New CR3s now get their camera, lens and date. CR3s already catalogued keep blank values until they’re re-analysed, because nothing forces that automatically.
- To fix them, re-index only the folders that hold CR3s: archivis index --force /Volumes/Archive1/<your R5 shoots>.
- That re-analyses those photos in full, so it’s slow on big folders.
- archivis inspect some. CR3 shows what’s read now.

7. The forks, once only. This needs a machine with gh signed in as someone allowed to create repositories in auteursoft:
```bash
tools/deps/fork.sh           # forks the 15 repositories and copies their version tags
tools/deps/fork.sh --check   # every line should say "ok"
```

After that, the weekly dependency check (Mondays 05:23 UTC) stops warning about missing forks.
